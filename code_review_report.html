二、严重 Bug

严重 Worker 缺少 onerror 处理 — 运行时异常导致游戏静默卡死
已修复

主线程只设置了 worker.onmessage，没有 worker.onerror。Worker 内部一旦抛出未捕获异常，主线程完全无感知，游戏会静默卡死在空白画面。

修复：添加 worker.onerror 回调 + Worker 内 onmessage 包裹 try/catch + 新增 workerError 消息类型 → 文件：main.js L487 · game_worker.js L457

严重 单线程降级模式 gameLoop 暂停时仍持续渲染 + 恢复时 deltaTime 跳变
已修复

gameLoop 无条件调用 engine.draw()，暂停时持续渲染浪费 CPU。且 lastTime 在暂停期间不更新，恢复瞬间 deltaTime 会是暂停的全时长，造成物理跳变。

修复：添加 isPaused/isRunning 守卫提前 return → 文件：main.js L1052-1062
